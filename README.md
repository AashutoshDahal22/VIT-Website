# VIT — IT Services Website

A modern, responsive website for VIT, an IT services company. Designed with a minimalist editorial approach, combining clean typography, structured layouts, and subtle interactions to create a professional digital presence.

## Overview

The VIT website serves as a digital presence for the company, showcasing its services, work, and business identity through a clean and accessible interface.

The design follows an editorial minimalism approach, drawing inspiration from Swiss design principles — strong typography, intentional whitespace, clear visual hierarchy, and a restrained color palette.

## Features

- **Responsive Design** — Optimized layouts for desktop, tablet, and mobile devices.
- **Minimalist Interface** — Clean typography, generous whitespace, and structured content.
- **Company Overview** — Dedicated section introducing VIT and its identity.
- **Services Showcase** — Organized presentation of the company's IT services.
- **Portfolio** — A dedicated space for showcasing projects and work.
- **Contact Section** — Clear contact information and business inquiry entry points.
- **Subtle Interactions** — Lightweight animations and transitions for a smoother experience.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd vit
```

Install dependencies:

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Generate a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Design Direction

The visual identity follows three core principles:

- **Clarity:** Content is structured to make information easy to navigate.
- **Simplicity:** Unnecessary visual elements are avoided in favor of purposeful design.
- **Consistency:** Typography, spacing, colors, and components follow a consistent visual system.
